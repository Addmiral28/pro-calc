# 🧮 Pro-Calc: Neumorphic Design Calculator

A polished, fully functional calculator built with a focus on modern UI/UX and clean code architecture. This isn't just a basic logic exercise; it features a professional design system and a persistent history log.



## 🚀 Live Demo
Check out the live project here:  
**[https://addmiral28.github.io/pro-calc/](https://addmiral28.github.io/pro-calc/)**

## ✨ Key Features
* **Neumorphic UI:** A soft, 3D extruded aesthetic using layered box-shadows.
* **History Sidebar:** A slide-out panel that tracks your calculations throughout the session.
* **Keyboard Support:** Full mapping for Numpad and standard keys (Enter for `=`, Esc for `AC`, Backspace for `DEL`).
* **Clean Logic:** Built using a JavaScript Class-based approach for better state management.
* **Responsive & Accessible:** Works on mobile and desktop, with visual feedback for keyboard presses.

## 🛠️ Tech Stack
* **HTML5:** Semantic structure.
* **CSS3:** Custom variables (CSS Properties) and Neumorphic styling.
* **JavaScript (ES6+):** Class-based logic, event delegation, and DOM manipulation.

## 📸 Preview
* **Dark Mode Support:** Adapts to the user's system preferences.
* **Smart Formatting:** Uses `toLocaleString` to handle large numbers and decimal precision.
